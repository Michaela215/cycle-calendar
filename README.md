# Cycle Calendar 🌸

Jednoduchý menstruační kalendář s důrazem na soukromí.

## Cíle projektu
- Žádná registrace, žádné reklamy, žádné zbytečné osobní údaje
- Data o cyklu zůstávají v telefonu
- Portfolio projekt: vývoj, testování (manuální, API, automatizované) a bezpečnost

## Technologie
- Flutter (aplikace)
- Python + FastAPI (receptář)
